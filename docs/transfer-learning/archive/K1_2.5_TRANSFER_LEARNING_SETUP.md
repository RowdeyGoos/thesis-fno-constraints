## Quick Usage Guide

```bash
# 1. Update checkpoint path (after k1_5 pretraining completes)
bash scripts/maintenance/update_k1_2.5_checkpoint_path.sh 12345678

# 2. Submit job array
sbatch scripts/slurm/finetune/poisson/submit_finetune_poisson_k1_2p5_array.sh

# 3. Monitor progress
squeue -u $USER
tail -f experiments/neuralop-poisson-k1_2p5-transfer-*.out
```

## Key Differences from k5_10 Transfer Learning

| Aspect | k5_10 (SYS-2) | k1_2.5 (SYS-1) |
|--------|---------------|----------------|
| Downstream domain | k∈[5,10] | k∈[1,2.5] |
| Domain relation | Extrapolation | Interpolation |
| Tensor format | 3-component | 3-component |
| Expected transfer | Moderate | Strong |

## Configuration Details

All configs use:
- Standard Poisson model (in_dim=4)
- 3-component tensor format
- 50 epochs max
- plot_figs: false (for speed)
- Cosine learning rate scheduler

Batch sizes optimized for sample count:
- 16 samples: batch_size=16
- 64 samples: batch_size=32
- 256 samples: batch_size=64
- 1k samples: batch_size=128
- 4k samples: batch_size=128

## Expected Outcomes

1. **Fine-tuning should outperform from-scratch** at all data sizes
2. **Transfer benefit largest at low data** (16-256 samples)
3. **Performance gap narrows** as data increases (4k samples)
4. **Faster convergence** for fine-tuned models

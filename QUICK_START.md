# Paper Reproduction Quick Reference

This directory contains the code for reproducing results from:
**"Towards Foundation Models for Scientific Machine Learning: Characterizing Scaling and Transfer Behavior of Neural Operators"** by Subramanian et al. (2023)

## 📚 Documentation

- **[REPRODUCTION_GUIDE.md](REPRODUCTION_GUIDE.md)** - Complete step-by-step reproduction guide
- **[DAIC_SETUP.md](DAIC_SETUP.md)** - Setup instructions for TU Delft DAIC cluster
- **[README.md](README.md)** - Original repository README

## 🚀 Quick Start

### 1. Verify Setup (5-10 minutes)

Run the automated quick test to verify everything works:

```bash
cd <repo-root>
chmod +x scripts/workflows/quick_test.sh
./scripts/workflows/quick_test.sh
```

This will:
- ✓ Generate a minimal test dataset (100 samples)
- ✓ Compute normalization scales
- ✓ Train FNO for 5 epochs
- ✓ Verify loss decreases

### 2. Full Reproduction

Follow the detailed guide in [REPRODUCTION_GUIDE.md](REPRODUCTION_GUIDE.md) for:
- Generating full datasets (32k samples each)
- Training all three PDE systems (Poisson, Advection-Diffusion, Helmholtz)
- Running scaling experiments
- Transfer learning experiments

## 📊 Expected Results

| PDE System | Test L2 Error | Training Time (4 GPUs) |
|------------|---------------|------------------------|
| Poisson (k∈[1,5]) | ~0.02-0.03 | ~10 hours |
| Advection-Diffusion | ~0.03-0.05 | ~10 hours |
| Helmholtz (ω∈[1,10]) | ~0.05-0.08 | ~10 hours |

## 🛠️ Helper Scripts

- **`compute_scales.py`** - Compute normalization statistics from training data
- **`scripts/workflows/quick_test.sh`** - Automated minimal test pipeline
- **`scripts/slurm/`** - SLURM job submission scripts for cluster use

## 💡 Troubleshooting

**Import errors?**
```bash
export PYTHONPATH=$(pwd):$PYTHONPATH
```

**CUDA out of memory?**
- Reduce batch size in config files
- Use fewer GPUs or smaller model

**DDP issues?**
- Try single GPU first for debugging
- Check firewall settings for multi-node training

See [REPRODUCTION_GUIDE.md](REPRODUCTION_GUIDE.md) for more troubleshooting tips.

# Experiments

This directory contains experiment logs, runs, and configuration snapshots.

## Structure

- `logs/`: Training logs (gitignored)
- `runs/`: TensorBoard/WandB runs (gitignored)
- `configs_used/`: Exact configuration files used for reported experiments in the thesis

## Usage

When running experiments, save the exact configuration used to `configs_used/` with a descriptive name for reproducibility.
